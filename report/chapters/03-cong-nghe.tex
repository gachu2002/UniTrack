\chapter{CÔNG NGHỆ SỬ DỤNG}

\section{Frontend với React và TypeScript}

Frontend của UniTrack được xây dựng bằng React và TypeScript. React hỗ trợ phát triển giao diện theo component, phù hợp với các màn hình có nhiều trạng thái như dashboard, workspace, chi tiết dự án và chi tiết nhiệm vụ. TypeScript giúp kiểm tra kiểu dữ liệu trong quá trình phát triển, giảm lỗi khi tích hợp với API backend \cite{react,typescript}.

\section{Backend với Go}

Backend sử dụng Go để xây dựng API REST. Go có ưu điểm là biên dịch nhanh, runtime gọn, thư viện chuẩn mạnh và phù hợp cho các dịch vụ Web cần xử lý đồng thời. Hệ thống sử dụng router HTTP, các handler theo từng lát tính năng và truy vấn SQL trực tiếp để kiểm soát rõ ràng luồng dữ liệu \cite{go}.

\section{Cơ sở dữ liệu PostgreSQL}

PostgreSQL được dùng làm hệ quản trị cơ sở dữ liệu quan hệ. Đây là lựa chọn phù hợp cho các nghiệp vụ cần ràng buộc toàn vẹn, giao dịch và truy vấn dữ liệu có quan hệ phức tạp như dự án, thành viên, nhiệm vụ, bài nộp và đánh giá \cite{postgresql}.

\section{RESTful API và phiên đăng nhập}

Frontend giao tiếp với backend thông qua API REST. Các endpoint sử dụng JSON làm định dạng trao đổi dữ liệu. Phiên đăng nhập được lưu bằng cookie, backend kiểm tra phiên hiện tại trước khi cho phép truy cập các tài nguyên được bảo vệ.
